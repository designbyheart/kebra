## Goal
A caller dials +1 (934) 647-8409 and talks to "Brianna", the Gulf Breeze Air front desk. Everything she knows and does goes through the tool registry; every call becomes a `calls` row that the office sees live.

## You own
`scripts/vapi-sync.ts`, `src/voice/prompt.ts` (system prompt builder), `src/voice/assistant.ts` (assistant config builder), `src/voice/webhook.ts` (handlers), `src/app/api/voice/webhook/route.ts`, `src/app/call/page.tsx` (+ client component) public web-call page, `src/domain/calls.ts` (create/update/finalize call rows), tests. Add deps `@vapi-ai/web` (client) and, if useful, `@vapi-ai/server-sdk` (or plain fetch against https://api.vapi.ai).

## Deliverables
1. **Assistant config as code** (`src/voice/assistant.ts`): built from the registry so tool schemas never drift (`z.toJSONSchema(def.input)`, tool `description` = registry description). Every function tool: `server.url = APP_URL + /api/voice/webhook`, `server.secret = VAPI_WEBHOOK_SECRET`, `async: false`, `messages: [{type:"request-start", content: <one short filler specific to the tool, e.g. "Let me pull up that address.">}]`, `timeoutSeconds: 10`. Model: provider `anthropic`, model `claude-sonnet-5` (query `GET https://api.vapi.ai/assistant` docs or try create; if Vapi rejects the string, fall back to the newest Claude Sonnet it accepts and report which), temperature 0.3, `maxTokens` 250. Transcriber: Deepgram nova-3 (or Vapi default) with keywords boost for street names? no; keep default with `endpointing` tuned for natural pauses. Voice: a warm American female voice (Vapi/11labs default catalog; pick one, note the id). `firstMessage`: "Gulf Breeze Air, this is Brianna. What's the service address I can help you with today?" `serverMessages`: status-update, transcript, tool-calls, end-of-call-report, hang. `endCallFunctionEnabled: true`. `transferCall` tool configured to `OFFICE_HANDOFF_NUMBER` when that env var is set (warm transfer with summary message "Transferring you to the office now"), otherwise omitted with a console warning. Silence timeout 20 s, max duration 15 min, background denoising on.
2. **System prompt** (`src/voice/prompt.ts`): implement PLAN.md §7 fully. Include: persona and speaking style (short sentences, one question at a time, read back specifics, say numbers and addresses the way a person would, never spell out IDs), business facts (Miami, 14 techs, hours from `business_hours`, 2-hour arrival windows, dispatch fee tiers if visible in service_types), the identification flow (address first, unit for multi-unit sites, then name; on `needs_unit` ask for the unit), what each tool is for and when to call it (dossier before answering history; check_warranty before any warranty statement; find_availability before offering times; never invent slots; book only after the caller confirms window and tech), handoff triggers (safety → give the safety instruction then transfer; billing disputes, complaints, legal/insurance, human requested twice, three failed identifications), guardrails (no door codes aloud, no prices beyond the price book, no other customers' info, no same-day promises without a slot, if a tool errors say so and offer the office), cancellation policy (request_cancellation, tell the caller the office will confirm), returning callers (use `{{caller_name}}` and `{{known_sites}}` template variables when present), current date/time `{{now_et}}`, and that the office sees everything live. Keep it under ~1,400 words; write it like an operations manual, not a chat persona.
3. **`scripts/vapi-sync.ts`** (`pnpm vapi:sync`): create the assistant on first run and store `VAPI_ASSISTANT_ID` in .env (append), update it on later runs (PATCH), attach it to phone number `VAPI_PHONE_NUMBER_ID` (PATCH `assistantId` and `server` for assistant-request), print a diff summary. Also set `APP_URL` usage: for local testing print the cloudflared instruction (`cloudflared tunnel --url http://localhost:3000`) and accept `--app-url` override.
4. **Webhook** (`/api/voice/webhook`): verify `x-vapi-secret` equals `VAPI_WEBHOOK_SECRET` (401 otherwise). Handle message types: `assistant-request` → look up `customer_phones` by caller number; respond `{ assistantId, assistantOverrides: { variableValues: { caller_name, known_sites, now_et } } }` (always set `now_et`); `status-update` → upsert `calls` (started → event `call.started`; ended → `call.ended`); `transcript` (final only) → append `{role, text, t}` to `calls.transcript` (jsonb append in SQL, not read-modify-write); `tool-calls` → dispatch each tool call through the registry with `ctx = { callId, actor: "agent", actorId: "vapi" }`, run them in parallel, append to `calls.tool_calls`, respond `{ results: [{ toolCallId, result: <JSON string of the envelope {ok, result, speech_hint} or error> }] }`; `end-of-call-report` → store summary, recording URL, ended reason, cost, full transcript from the report if longer than ours; `hang` → event `call.hang`. Also handle `transfer-update`/transfer failures if Vapi sends them → events `call.transfer_attempted` / `call.transfer_failed`. Respond within 1 s to everything except tool-calls. Set `export const maxDuration = 30`.
5. **Call rows**: `src/domain/calls.ts` with `upsertCallFromStatus`, `appendTranscript`, `recordToolCall`, `finalizeCall`; when a tool like `find_address`/`book_job` identifies a customer, set `calls.matched_customer_id/address_id` (do this inside the webhook after a successful tool result, not inside the tools) and emit `call.identified` once.
6. **Web call page** `/call` (public, no login; add it to the proxy public list by editing ONLY the `PUBLIC_EXACT` set in `src/proxy.ts`): big "Call Gulf Breeze Air" button using `@vapi-ai/web` with `NEXT_PUBLIC_VAPI_PUBLIC_KEY` and `VAPI_ASSISTANT_ID` (expose as `NEXT_PUBLIC_VAPI_ASSISTANT_ID` at build time or fetch from a tiny public endpoint), live status (connecting / listening / speaking), mute, hang up, and the phone number printed for people who prefer to dial. Same assistant, so web calls land on the platform identically (direction `web`).
7. **End-to-end test on the real number**: deploy (`railway up --detach` from the repo root, then wait for health), run `pnpm vapi:sync --app-url https://kebra-web-production.up.railway.app`, then place at least three web calls yourself through the Vapi API or the `/call` page?
